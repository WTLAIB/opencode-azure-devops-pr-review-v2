# OpenCode Azure DevOps PR Review V2 — 0.1.0

Release notes draft. Publish these notes with the reviewed release commit;
this file does not mean that the tag or GitHub Release exists yet.

Review Azure DevOps pull requests in OpenCode, preview the resulting comments,
and choose when to publish them.

## Included

- `/pr-check`: check Azure access, source reads and model readiness without
  calling a model.
- `/pr-quick`: one reviewer per shard covers function and risk. Findings are
  reported, not independently verified.
- `/pr-review` and `/pr-deep`: separate functional and risk reviews, followed
  by independent verification sessions. `/pr-deep` runs the same review with
  the stronger models configured in `models.deep`.
- `/pr-comment`: preview the summary and inline comments. Add `--publish` to
  post the saved plan; publication checks the PR head, skips existing markers
  and reads posted comments back.
- `/pr-stop`: cancel the active command in your conversation.
- Large-PR sharding, overflow recovery, bounded retries and two concurrent
  comment-planning pages.
- Private saved reviews and publication records, and Azure proxy/CA settings.
- The PAT kept alone in an owner-only file (`azure.patFile`), so
  `settings.json` holds no secret.

## Installation

Download and extract this release's source archive. Follow `docs/QUICKSTART.md`
inside it, skipping the Git clone and checkout commands; the archive already
supplies the source. Run `install.sh` with the configuration
directory used by your OpenCode V2 instance. Set your own Azure organization,
PAT and OpenCode model IDs, then restart OpenCode.

For an existing AZPR V2 installation, use the documented `--replace` option;
it preserves settings and adds defaults. This release is distributed as source
with an installer, not as an npm package.

## Compatibility and evidence

- Tested host: `@opencode/cli` **2.0.32**.
- Tested OS: **Ubuntu 22.04**; the recorded environment uses WSL2.
- Azure: **Azure DevOps Services**, REST API **7.1**.
- Installer: POSIX `sh` and Python 3 standard library. No build step or npm
  dependencies are needed for the plugin.

`docs/VALIDATION.md` records the offline tests, real-host tests with fake
services, and separate live Azure/model runs. Model quality and runtime
correctness are different claims; test counts do not establish review accuracy.

## Before using it with a team

Read `docs/ENTERPRISE.md` for data sent to the selected model, PAT permissions,
private retention, network configuration and publication behavior.

Quick findings are not independently verified. Preview generation uses a model
and can incur cost. A session can make multiple model requests; no fixed cost
or accuracy is promised. Azure DevOps Server is not supported; operating
systems other than the tested Linux environment remain unvalidated. The minimum
recommended PAT scopes were confirmed live; publication of quick reviews remains
open.
