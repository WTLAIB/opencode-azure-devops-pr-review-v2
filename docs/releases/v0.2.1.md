# OpenCode Azure DevOps PR Review V2 — 0.2.1

AZPR is now available from the npm registry. This release changes packaging
and documentation only: the runtime, prompts and settings are the same as in
0.2.0.

## Installation

```sh
opencode plugin add opencode-azure-devops-pr-review@0.2.1
```

The same release remains available as a versioned Git package, which needs
Git but not the npm registry:

```sh
opencode plugin add 'github:WTLAIB/opencode-azure-devops-pr-review-v2#v0.2.1'
```

Add only one of them. Follow the [quickstart](https://github.com/WTLAIB/opencode-azure-devops-pr-review-v2/blob/v0.2.1/docs/QUICKSTART.md)
for `/pr-setup`, a private PAT file, service restart and your first review.
The source archive includes `install.sh` for manual installation. Use one
installation method per OpenCode profile.

## Upgrading

For a native installation, edit the existing AZPR entry in the OpenCode
configuration's `plugins` list:

- To stay on Git, change `#v0.2.0` (or `#v0.1.0`) to `#v0.2.1`.
- To move to npm, replace the Git specification with
  `opencode-azure-devops-pr-review@0.2.1`.

If the entry is an object, change only its `package` value; preserve
`options.settingsFile` and other options. Keep one AZPR entry, then restart the
OpenCode service. npm and Git installations read the same external settings, so
the settings, PAT file and review records stay in place and a working
configuration needs no new `/pr-setup`. Exact versions stay pinned:
`opencode plugin update` leaves them unchanged, so change the version yourself
for later releases.

Coming from 0.1.0, you also gain automatic comments, which stay disabled until
you configure them; see the
[0.2.0 notes](https://github.com/WTLAIB/opencode-azure-devops-pr-review-v2/blob/v0.2.0/docs/releases/v0.2.0.md#upgrading-from-010).

For a source installation, extract the new archive and run its installer with
`--replace`. Only documentation differs from 0.2.0 there, so this is optional.

```sh
sh install.sh --config-dir /absolute/path/to/v2-opencode-config --replace
```

## Compatibility and release assets

The tested target remains OpenCode CLI **2.1.2**, Node.js **22.23.3**, Ubuntu
**22.04.5** under WSL2, and Azure DevOps Services REST API **7.1**.
[Validation](https://github.com/WTLAIB/opencode-azure-devops-pr-review-v2/blob/v0.2.1/docs/VALIDATION.md)
records the release checks. Azure DevOps Server and other operating systems
remain unvalidated.

The npm package is built from this tag with `npm pack` and has no
dependencies or install scripts. Release assets are the source archive
`opencode-azure-devops-pr-review-v2-0.2.1.tar.gz` and `SHA256SUMS`; verify
downloads with `sha256sum -c SHA256SUMS`. The demonstration video stays
attached to [v0.2.0](https://github.com/WTLAIB/opencode-azure-devops-pr-review-v2/releases/tag/v0.2.0).
