# Azure DevOps PR Review for OpenCode — 0.3.2

This release shows AZPR's actual Azure DevOps output at the top of the README,
states the COMPLETE status more precisely in receipts, and slims the npm
package to the runtime. Reviews, comment previews, adjustments and publication
work as in 0.3.1.

## What changed

- **See the output first.** The README opens with an actual inline comment on
  a dedicated test PR, shown with its code context, and the complete PR summary
  from the same review. The first-review steps follow, then the 15-second
  recording of adjusting findings and publishing. The
  [demo](https://github.com/WTLAIB/opencode-azure-devops-pr-review-v2/blob/v0.3.2/docs/DEMO.md#actual-azure-devops-comments)
  records the capture run and its editing, and lists the pictured comments as
  text.
- **Precise status.** COMPLETE in a receipt now means that no source-commit
  change was detected. When the final version recheck itself fails, the review
  stays COMPLETE and its report lists a warning; publication still rechecks
  that the PR is active and its source commit is unchanged before posting.
- **Smaller npm package.** The package holds the runtime (`server.js` and
  `src/`), the README, the changelog and the license: 32 files and about 170 KB
  instead of 76 files and 1.35 MB. Documentation, media, installers and the
  settings example and schema remain in the repository and the source archive,
  and npmjs.com shows the README's links and images from GitHub.
- **Documentation.** The README and the architecture guide list the commands
  that answer directly instead of starting a background run, and the README
  and the commenting guide state that repeating the saved adjustments plans
  nothing.

## Installation

```sh
opencode plugin add opencode-azure-devops-pr-review@0.3.2
```

Alternatively, install the same release from Git:

```sh
opencode plugin add 'github:WTLAIB/opencode-azure-devops-pr-review-v2#v0.3.2'
```

Add only one of them. Follow the
[quickstart](https://github.com/WTLAIB/opencode-azure-devops-pr-review-v2/blob/v0.3.2/docs/QUICKSTART.md)
for a private PAT file, `/pr-setup`, a service restart and the first review.

## Upgrading

For an entry that `opencode plugin add` created, add 0.3.2 and remove the
previous version only when the download succeeded. Replace `PREVIOUS_VERSION`
with the version in your `plugins` entry, such as 0.3.1:

```sh
opencode plugin add opencode-azure-devops-pr-review@0.3.2 &&
  opencode plugin remove opencode-azure-devops-pr-review@PREVIOUS_VERSION
```

Run them when no AZPR command is running: OpenCode 2.1.4 switches the running
service to 0.3.2 within seconds, without a restart, and `opencode plugin list`
should then show a single `azpr` row with 0.3.2. Running only the first command
leaves the previous version running. For an entry with options, change only
its `package` value; the OpenCode service then downloads 0.3.2 with its own
network settings. See
[upgrading](https://github.com/WTLAIB/opencode-azure-devops-pr-review-v2/blob/v0.3.2/README.md#upgrading)
for the details. External settings, the PAT file and review records remain in
place, and this release adds no settings or required migration.

For a source installation, extract the new archive and run its installer with
`--replace` to retain settings:

```sh
sh install.sh --config-dir /absolute/path/to/v2-opencode-config --replace
```

## Compatibility and validation

The tested target remains OpenCode CLI **2.1.4** (V2 plugin API), Node.js
**22.23.3**, Ubuntu **22.04.5** under WSL2, and Azure DevOps Services REST API
**7.1**. OpenCode 1.x and Azure DevOps Server are not supported; other operating
systems remain unvalidated.

The [validation record](https://github.com/WTLAIB/opencode-azure-devops-pr-review-v2/blob/v0.3.2/docs/VALIDATION.md)
describes the release checks with fake services. The runtime changes only the
receipt's status sentence, so this release needed no new live model run; the
README screenshots come from a live run with 0.3.1 on 2026-10-29.

The npm package, Git package and source archive contain the same runtime, with
no npm dependencies or install scripts; the source archive also contains the
documentation, installers and settings example. The release source artifact is
`opencode-azure-devops-pr-review-v2-0.3.2.tar.gz`, with checksums in `SHA256SUMS`.
